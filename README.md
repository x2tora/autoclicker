# 오토 클리커 (AutoClicker) 🎯📱

**원하는 화면 위치를 원하는 속도와 규칙으로 정확하게 자동 터치해 주는 안드로이드 전용 오토 클리커입니다.**

게임 반복 작업, 잦은 버튼 터치, 테스트 자동화 등 손가락으로 계속 눌러야 하는 번거로운 작업을 깔끔한 플로팅 패널로 간편하게 대신해 줍니다.

---

## ✨ 주요 기능 소개

### 1. 단일 타겟 모드 (Single Target)
- **한 지점 집중 클릭**: 화면 위의 조준경 과녁(`1`)을 원하는 위치로 드래그해서 놓으면 그 자리를 자동으로 반복 클릭합니다.
- **자유로운 시간 단위 설정**: 클릭 간격과 클릭 지속시간(화면을 누르고 있는 시간)을 **`ms`(밀리초) · `s`(초) · `m`(분) · `h`(시간)** 단위로 자유롭게 지정할 수 있습니다. (기본 단위: `ms`)
- **3가지 반복 종료 조건**:
  - **멈출 때까지 계속 클릭**: 일시정지 또는 닫기 버튼을 누를 때까지 무한 반복
  - **일정 시간 동안 지속**: 정해진 시간(`ms`/`s`/`m`/`h`)이 지나면 자동 종료
  - **반복 횟수 직접 입력**: 원하는 횟수만큼 정확히 클릭한 뒤 자동 종료
- **봇 방지 랜덤 터치**: 선택한 원형 영역 안에서 매번 조금씩 다른 무작위 좌표를 눌러 반복 패턴 감지를 줄여줍니다.

---

### 2. 다중 타겟 모드 (Multi Target)
- **순차 다중 클릭**: 화면 여러 곳에 번호가 매겨진 타겟 지점(`1`, `2`, `3`...)을 배치해 순서대로 자동 클릭합니다.
- **즉석 추가·제거·개별 수정**:
  - 화면 위 컨트롤 패널의 **`+` / `−`** 버튼이나 앱 안에서 타겟 지점을 손쉽게 추가·삭제할 수 있습니다.
  - 각 번호 지점을 탭하면 해당 지점만 따로 간격·지속시간·봇 방지 랜덤 반경을 다르게 설정할 수 있습니다.

---

### 3. 한눈에 조작하는 플로팅 오버레이 2종
- **플로팅 컨트롤 패널**: 화면 한쪽에 떠 있는 슬림한 캡슐형 패널을 드래그해 편한 곳에 둘 수 있습니다.
  - **`✕` 닫기**: 오버레이와 자동 클릭을 즉시 종료합니다.
  - **`⚙` 설정**: 다른 앱을 켠 상태에서도 패널 위에서 곧바로 클릭 간격·지속시간·반복 조건·봇 방지 옵션을 바꿀 수 있습니다.
  - **`＋` / `－` 버튼** *(다중 모드)*: 타겟 지점을 즉시 추가하거나 마지막 지점을 삭제합니다.
  - **`▶` / `⏸` 시작·일시정지**: 클릭을 바로 시작하거나 멈추며, 아래에서 **경과 시간 · 남은 반복 조건 · 누적 클릭 수**를 실시간으로 확인할 수 있습니다.
- **조준경 타겟 지점**: 반투명 과녁 디자인으로 아래 화면의 버튼 글자가 가려지지 않으며, 봇 방지 옵션을 켜면 클릭이 분산되는 파란 점선 영역도 함께 표시됩니다.

---

### 4. 프리셋 보관함 · 터치 테스트 · 테마 · 백업
- **프리셋 저장 및 원탭 실행**: 자주 쓰는 단일·다중 타겟 배치와 속도 설정을 이름으로 저장해 두고, 탭 한 번으로 불러와 바로 실행할 수 있습니다.
- **내장 터치 테스트장**: 다른 앱으로 나가기 전에 앱 안의 과녁 보드 위에서 실제 클릭 속도(CPS)와 봇 방지 랜덤 탄착군을 미리 시험해 볼 수 있습니다.
- **다크/라이트 테마 & 컬러 커스터마이징**: 시스템 설정 따름/라이트/다크 모드와 **기본 블루 · Material You · 커스텀 색상(직접 색상 선택)**을 지원합니다.
- **안전한 JSON 백업 및 인앱 업데이트**: 모든 설정과 프리셋을 JSON 파일이나 클립보드 텍스트로 내보내고 복원할 수 있으며, 새 버전이 나오면 앱 안에서 바로 내려받아 업데이트할 수 있습니다.

## 📲 다운로드 및 설치 방법

[GitHub Releases](https://github.com/x2tora/autoclicker/releases) 페이지에서 내 안드로이드 기기에 맞는 APK 파일을 내려받아 설치하세요.

| 파일 이름 | 추천 기기 |
|---|---|
| **`autoclicker-v1.0.0-arm64-v8a.apk`** | **대부분의 최신 안드로이드 스마트폰 (가장 추천)** |
| `autoclicker-v1.0.0-armeabi-v7a.apk` | 오래된 구형 32비트 안드로이드 기기 |
| `autoclicker-v1.0.0-x86_64.apk` / `x86.apk` | 일부 태블릿·크롬북·PC 에뮬레이터 |
| `autoclicker-v1.0.0-universal.apk` | 기기 종류를 잘 모를 때 (모든 기기 호환 통합본) |

### 처음 실행 시 권한 안내
1. 다운로드한 `.apk` 파일을 눌러 **"출처를 알 수 없는 앱 설치 허용"** 안내가 나오면 허용한 뒤 설치합니다.
2. 앱을 열고 **[접근성 설정 열기]**를 눌러 **설치된 앱(또는 다운로드한 앱) → 오토 클리커**의 접근성 스위치를 켜 주세요.
3. 앱으로 돌아와 **단일 타겟** 또는 **다중 타겟** 화면에서 **[오버레이 띄우기]**를 누르면 화면 위에 컨트롤 패널과 타겟 과녁이 나타납니다.
4. 원하는 버튼 위에 과녁을 드래그해 올려놓은 뒤 컨트롤 패널의 **`▶`** 버튼을 누르면 자동 클릭이 시작됩니다.
